# Rye & Rose Bakery

Rye & Rose Bakery is a simple bakery website built using HTML, CSS, and JavaScript.

The project includes a bakery homepage, product listing, product management, search, filtering, sorting, and CRUD operations using Local Storage.

---

## Project Overview

The website represents an online bakery where users can view bakery products and manage products using JavaScript.

### Main Features

- Bakery homepage
- Navigation between Home and Shop
- Hero section
- Featured products
- Product cards
- Add Product
- View Products
- Edit Product
- Delete Product
- Search Products
- Filter Products by Category
- Sort Products by Price
- Local Storage
- Responsive design
- Product image fallback

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Google Fonts
